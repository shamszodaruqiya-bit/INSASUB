INFASUB — полный сайт (клиент + сервер)

ФАЙЛЫ
  index.html    весь сайт в одном файле (уже настроен на https://infasub-api.onrender.com)
  abramyan.js   книга Абрамяна внутри JavaScript (грузится только при нажатии «Читать»)
  server.js     сервер на Node.js (вход по коду из почты, список пользователей, сообщения, статус «в сети»)
  package.json  .gitignore

КАК ОБНОВИТЬ
1) Замените index.html и server.js в вашем репозитории и сделайте деплой на Render.
   Переменные окружения те же: BREVO_API_KEY, SENDER_EMAIL, SITE_URL (SENDER_NAME по желанию).
   Для постоянного хранения добавьте ещё две: UPSTASH_REDIS_REST_URL и UPSTASH_REDIS_REST_TOKEN (инструкция ниже).
   Файл abramyan.js загрузите в репозиторий один раз; дальше при обновлениях достаточно index.html и server.js.
2) server.js нужно заменить обязательно: в нём новые действия для лидеров и олимпиады.
3) Те, кто входил раньше, один раз войдут заново: сервер выдаст им сессию.

КНИГА АБРАМЯНА
  Книга лежит внутри JavaScript-файла abramyan.js (рядом с index.html, в корне репозитория, без папок).
  Сайт подгружает её только когда человек нажимает «Читать» (около 15 МБ, один раз, потом из кэша браузера),
  поэтому обычные страницы сайта открываются быстро.
  При обновлении просто загружайте index.html и server.js, а abramyan.js достаточно загрузить один раз.
  Книга видна в «Электронных книгах» на таджикском языке (TJ) и читается прямо на сайте.
  Чтобы заменить книгу, сделайте новый abramyan.js из PDF (base64) и загрузите его с тем же именем.
  Старая папка books/ больше не нужна (сайт обращается к ней только если abramyan.js не найден).

ЧТО РАБОТАЕТ
- При открытии сайта сначала экран регистрации / входа, сайт открывается после входа.
  На этом экране видно участников и сколько их в сети.
- Раздел «Пользователи» с общим списком, статусом «в сети», страной, городом.
- Сообщения между пользователями с уведомлением (цифра) и блоком «Мои сообщения» в профиле.
- Огонёк (серия дней), чат-бот AI. У каждой темы и каждой формулы есть пояснение с примерами (нажмите на карточку).
- В «Задачи и тесты» по 20 вопросов в каждом предмете (всего 120). Решения в тестах не показываются.
- «Лидеры»: таблица по огонёчку (серия дней подряд) и итоги олимпиады; общая для всех участников (хранится на сервере).
- «Олимпиада»: сначала регистрация на олимпиаду, потом 6 предметов по 20 задач, 30 минут и одна попытка на предмет, 1 балл за верный ответ; места по сумме баллов, при равенстве по времени.
- Автосохранение: каждые 15 секунд сайт сам сохраняет прогресс. Маленький значок ☁ / ✓ вверху рядом с огоньком (наведите мышь — подсказка); введённые, но не проверенные ответы тоже сохраняются. Если ничего не менялось, лишних запросов на сервер не отправляется.
- Прогресс (решённые задачи) сохраняется в аккаунте на сервере и подтягивается на другом устройстве.
- Сообщения: кнопка «✉ Сообщение» (справа внизу) и кнопка «Мои сообщения» в профиле открывают отдельный экран:
  слева все переписки (с числом непрочитанных), справа выбранная переписка и поле для ответа.
  «Новое сообщение» позволяет найти любого человека и написать ему. Новые сообщения подтягиваются сами (раз в 5 секунд, пока экран открыт).
- Профиль другого человека (клик в «Пользователях» или «Лидерах») больше не показывает переписку: там кнопки «Отправить сообщение» и «Мои сообщения».
- Статусы своих сообщений: ✓ Отправлено, ✓✓ Доставлено (устройство получателя получило), ✓✓ Прочитано (человек открыл переписку; видно время).
- Удаление: «⋯» у сообщения → «Удалить у меня» (скрывает только у вас) или «Удалить у всех» (только для ваших сообщений; исчезает у обоих).
  «Удалить переписку у меня» убирает всю переписку только у вас.
- Сообщения отправляются только через сервер. Если связи нет или сессия устарела, сайт честно пишет «Сообщение НЕ отправлено» и предлагает войти заново.
- При регистрации указывается страна; в полях пароля есть значок-глаз (показать пароль).

ВАЖНО
- На бесплатном Render сервер «засыпает», первый запрос может идти до минуты.
- Данные в файле data.json на бесплатном Render стираются при каждом обновлении сайта. Поэтому пользователи «пропадают».
  Решение ниже («ПОСТОЯННОЕ ХРАНИЛИЩЕ»).

Замечание про честность олимпиады: ответы проверяются в браузере (сайт без отдельной базы заданий на сервере), поэтому это учебная олимпиада. Сервер ограничивает баллы (до 20 на предмет), время и «дни» огонька (не раньше даты регистрации).

ПОСТОЯННОЕ ХРАНИЛИЩЕ (чтобы пользователи не пропадали при обновлении)
Почему пропадают: на бесплатном Render диск стирается при каждом деплое и перезапуске, а сервер хранил всё в файле data.json.
Что сделать (бесплатно, 5 минут):
 1) Зайдите на https://upstash.com, зарегистрируйтесь и создайте базу Redis (Create Database, тариф Free).
 2) На странице базы найдите блок «REST API» и скопируйте два значения:
      UPSTASH_REDIS_REST_URL
      UPSTASH_REDIS_REST_TOKEN
 3) На Render откройте ваш сервис → Environment → добавьте эти две переменные с теми же именами → Save.
 4) Замените server.js на файл из этого архива и сделайте деплой.
 5) Проверка: откройте адрес сервера в браузере, там должно быть "storage":"remote","ready":true.
    В логах Render будет строка «storage: Upstash Redis (постоянное)».
После этого пользователи, сообщения, серии огонька, олимпиада и прогресс хранятся в Upstash и переживают любые обновления.
Если data.json ещё существует на момент первого запуска, сервер сам перенесёт его в Upstash. Кто успел пропасть раньше, должен зарегистрироваться заново.
Вместо Upstash можно купить Render Disk и задать DB_FILE=/var/data/data.json.
Сервер сохраняет данные в Upstash автоматически (через доли секунды после изменений и при остановке), пока данные не загрузились, он ничего не записывает, поэтому базу нельзя затереть пустой.
