INFASUB — полный сайт (клиент + сервер)

ФАЙЛЫ
  index.html    весь сайт в одном файле (уже настроен на https://infasub-api.onrender.com)
  server.js     сервер на Node.js (вход по коду из почты, список пользователей, сообщения, статус «в сети»)
  package.json  .gitignore

КАК ОБНОВИТЬ
1) Замените index.html и server.js в вашем репозитории и сделайте деплой на Render.
   Переменные окружения те же: BREVO_API_KEY, SENDER_EMAIL, SITE_URL (SENDER_NAME по желанию).
2) Те, кто входил раньше, один раз войдут заново: сервер выдаст им сессию.

ЧТО РАБОТАЕТ
- При открытии сайта сначала экран регистрации / входа, сайт открывается после входа.
  На этом экране видно участников и сколько их в сети.
- Раздел «Пользователи» с общим списком, статусом «в сети», страной, городом.
- Сообщения между пользователями с уведомлением (цифра) и блоком «Мои сообщения» в профиле.
- Огонёк (серия дней), чат-бот AI, во всех предметах у каждой темы есть описание (нажмите на карточку темы).

ВАЖНО
- На бесплатном Render сервер «засыпает», первый запрос может идти до минуты.
- data.json на бесплатном Render может обнуляться при новом деплое. Для постоянного хранения подключите Render Disk
  (переменная DB_FILE=/var/data/data.json) или базу данных.
